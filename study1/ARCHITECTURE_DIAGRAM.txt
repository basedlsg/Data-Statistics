┌─────────────────────────────────────────────────────────────────────────────┐
│                          DATA FLOW PIPELINE                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  Experiment Execution
         ↓
  [SessionManager.run_session()]
         ↓
  For each condition in order:
    1. Start condition
    2. Run N interactions → [InteractionLogger.log_interaction()]
    3. End condition
    4. Washout period (if not last)
         ↓
  Raw JSONL files in data/raw/
         ↓
  [DataValidator.run_all_validations()]
    • Check completeness
    • Verify counterbalancing
    • Detect duplicates
    • Analyze quality
         ↓
  Validation Reports in data/validation/
         ↓
  [DataAggregator.create_analysis_datasets()]
    • Load all interactions
    • Aggregate to session-level
    • Aggregate to agent-level
         ↓
  CSV files in data/processed/
         ↓
  Statistical Analysis
    • Load agent_level.csv
    • Mixed-effects models
    • Effect size calculations

┌─────────────────────────────────────────────────────────────────────────────┐
│                       COUNTERBALANCING DESIGN                                │
└─────────────────────────────────────────────────────────────────────────────┘

  5×5 Latin Square (Each condition appears once in each position)

  Position:    1         2         3         4         5
  ──────────────────────────────────────────────────────────────
  Order 0:   Control → Temp0.7 → Temp1.2 → TopP   → Penalty
  Order 1:   Temp0.7 → Temp1.2 → TopP    → Penalty → Control
  Order 2:   Temp1.2 → TopP    → Penalty → Control → Temp0.7
  Order 3:   TopP    → Penalty → Control → Temp0.7 → Temp1.2
  Order 4:   Penalty → Control → Temp0.7 → Temp1.2 → TopP

  Assignment: Balanced across agents to ensure equal representation

┌─────────────────────────────────────────────────────────────────────────────┐
│                         KEY DESIGN DECISIONS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  1. JSONL Format
     ✓ Append-only (safe for concurrent writes)
     ✓ Line-oriented (streaming friendly)
     ✓ Human-readable (easy debugging)

  2. Atomic Writes with File Locking
     ✓ fcntl.flock() for exclusive access
     ✓ Retry logic with exponential backoff
     ✓ Error logging to separate files

  3. Latin Square Counterbalancing
     ✓ Controls for order effects
     ✓ Balanced design
     ✓ Statistical power

  4. Multi-level Aggregation
     ✓ Interaction-level (raw)
     ✓ Session-level (descriptive)
     ✓ Agent-level (analysis)

  5. Comprehensive Validation
     ✓ Automated quality checks
     ✓ Timestamped reports
     ✓ Pass/fail criteria
