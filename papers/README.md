## How to Use These Papers

### For Calibration

1. **Baker & Wurgler (2006)**: Use sentiment proxy methodology to construct Hype(t) empirically
2. **Gompers et al. (2016)**: Extract actual VC decision weights from survey data
3. **Greenwood & Hanson (2015)**: Calibrate transition matrix from credit cycle data

### For Validation

1. **Ewens & Townsend (2020)**: Compare model predictions to real funding bias patterns
2. **Kortum & Lerner (2000)**: Validate regional innovation patterns
3. **Farmer & Foley (2009)**: Apply complexity economics validation framework

### For Methodology

1. **Arthur et al. (1997)**: Reference for artificial market design
2. **Pattern-Oriented Modeling**: Use for model structure validation

## Citation Format

All papers should be cited using APA 7th edition. Example:

```
Ewens, M., & Townsend, R. R. (2020). Are early stage investors biased against women?
Journal of Financial Economics, 135(3), 653-677.
```
